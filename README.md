# Oxygen Kernel for Xiaomi 12 (cupid)

Custom GKI kernel built for OxygenOS 16 ports on the Xiaomi 12 (`cupid`), powered by Snapdragon 8 Gen 1 (SM8450).

## Features
- **KernelSU & SuFS** integration for advanced root management.
- **Custom Undervolting (UV)** tables for better thermal efficiency and battery life.
- **Optimized Low Power Mode (LPM)** for improved standby performance.
- Based on GKI architecture.
